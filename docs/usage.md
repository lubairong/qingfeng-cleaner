# 使用手册 · Usage

> 清风清理 QingFeng Cleaner — Windows 11 的 C 盘清理与空间透视工具。
> 目标读者：想安全释放 C 盘空间、想知道空间都去哪了、又不想装全家桶的普通用户。

---

## 1. 安装

### 方式 A：打包版（推荐给普通用户）—— 目录版 + 启动 bat

**唯一交付形态是目录版**，双击 `启动清风清理.bat` 即可运行：

1. 下载 `QingFengCleaner-onedir.zip`，解压到任意目录（例如 `D:\Tools\QingFengCleaner\`）。
2. 解压后应有 `启动清风清理.bat` 和 `QingFengCleaner-onedir\`（内含 `QingFengCleaner.exe` 与 `_internal\`）。
   **整个目录一起用**，不要只拷走 exe。
3. 双击 `启动清风清理.bat`（或直接双击 `QingFengCleaner-onedir\QingFengCleaner.exe`）。
4. 首次启动 Windows SmartScreen 可能提示「未知发布者」——这是未签名的开源小工具的正常现象，
   点「更多信息 → 仍要运行」即可。源码全部公开，可自行审计。

> **没有单文件版**：PyInstaller 单文件 exe 启动时要先把自己解压到临时目录，实测在中文路径下会弹
> `Could not create temporary directory!` 并挂起，因此不作为交付物。需要实验可
> `packaging\build.ps1 -OneFile`（产物在 `dist\_experimental\`）。

免安装、不写注册表、不常驻服务；空间索引缓存写在 `%LOCALAPPDATA%\QingFengCleaner\space_index.json`。

### 方式 B：源码运行（推荐给开发者 / 想审计代码的人）

需要 **Python 3.12**（必须包含 tkinter，官方安装包默认包含）。

```bat
:: 项目根目录下
packaging\run_dev.bat
```

或者直接：

```bat
python main.py
```

本项目**零第三方依赖**，不需要 `pip install` 任何东西。

启动后你会看到：

```

├──────────────────────────────────────────────────────┤
│  ☑ 名称                  大小        文件数     风险   │
│  ▼ 系统                                              │
│    ☑ 用户临时文件        1.2 GB       8,431    安全   │  ← 规则列表
│    ☑ Windows 日志        320 MB       1,204    安全   │
│    ☐ 休眠文件            6.1 GB       —        高级   │
│  ▼ 浏览器                                            │
│    ☑ Edge 缓存           1.8 GB       22,010   安全   │
│  ...                                                 │
├──────────────────────────────────────────────────────┤
│  [开始扫描]  [清理选中]  [设置]   ▓▓▓▓▓░░░░ 62%       │  ← 操作区
└──────────────────────────────────────────────────────┘
```

典型流程：

1. 点「开始扫描」，等待进度条走完（全盘规则扫描通常 10~60 秒）。
2. 查看各分类的可清理体积，**按需取消勾选**你不想动的项。
3. 点「清理选中」→ 弹出二次确认框，核对「将释放多少 / 是否走回收站 / 高级规则数量」。
4. 确认后执行清理。**默认走回收站**，删错了可以还原。

### 风险等级

| 等级 | 含义 | 默认 |
|---|---|---|
| 安全 | 临时文件、缓存、日志，删除无副作用 | 勾选 |
| 谨慎 | 可能影响某些软件首次启动速度、历史记录 | 勾选（部分关闭） |
| 高级 | 隐私痕迹、系统维护类，误删可能影响功能 | **不勾选**，需手动开启 |

### 系统托盘

- 关闭主窗口 = 最小化到托盘，不是退出。
- 托盘右键菜单：**显示主窗口 / 快速扫描 / 退出**。
- 想关闭「最小化到托盘」行为：设置里取消勾选，或用 `--no-tray` 不启用托盘。

### 2.1 空间透视页（v2）

顶部导航切到「空间透视」，或用 `python main.py --page space` 直接进入。页面从上到下：

1. **磁盘构成条**：把 C 盘「已用」拆成 系统 / 用户 / 程序 / 休眠与交换 / 受保护（还原点、回收站、无权限目录）
   五段，标 GB 与占比。受保护部分会显式列出，不会假装不存在。
2. **目录树 + Treemap**：左侧树按大小降序；右侧 Treemap 色块面积=大小，**点击下钻、双击在资源管理器打开**，
   顶部面包屑可返回上级。
3. **大文件决策表**：列出 ≥100 MB 的大文件，按分类分组（安装包/升级残留、程序旧版本副本、备份、开发缓存、
   视频/镜像、其它、建议保留），每行给出「建议 + 一句话理由 + 修改时间/年龄」。
4. **系统占用卡片**：WinSxS / 休眠 / 页面文件 / 还原点 / 回收站，每项显示大小与建议命令，可「复制命令」
   或「以管理员身份打开 PowerShell」——**工具不会替你执行这些命令**。

索引与缓存：

- 首次进入会在后台扫描 C 盘（只读、按 inode 去重、跳过 junction/symlink），有进度条、可取消；
- 完成后缓存 24 小时，再次打开**秒开**；「重新扫描」按钮可强制重建；
- 索引不上传、不写注册表。默认最多展示 800 个大文件项。

> 实现细节（索引模型、授权矩阵、迁移规则）见 [`docs/ARCHITECTURE-V2.md`](ARCHITECTURE-V2.md)。

#### 空间页的两个动作

| 动作 | 说明 | 安全边界 |
|---|---|---|
| **移入回收站** | 勾选 → 二次确认；可还原，**空间页没有永久删除** | 受保护/系统/程序目录按钮禁用并显示原因 |
| **迁移到目标** | 选目标盘（D:/E: 等固定磁盘）→ 二次确认 → 后台复制并显示进度 | 只能迁到其它固定盘；保留 `<目标盘>\C_mirror\<原相对路径>`；**复制成功后才删源**；失败或取消时源文件不动 |

迁移确认框会写明目标盘、目标根目录与「复制成功后才删除源文件」；迁移过程中可「取消迁移」，
已完成的保留、未完成的源文件不动。

「受保护·不可操作」是什么意思：该文件位于 `C:\Windows`、`C:\Program Files`、`C:\ProgramData`（除个别
安装包下载目录）等区域，删除可能破坏系统或程序，因此工具只展示、不允许操作；「建议保留」组（模型/数据库/
微信数据等）默认不勾选。

### 2.2 管理员模式（提权）

**不提权也能用**：普通用户下可以清理自己的 `%TEMP%`、浏览器/应用缓存、回收站，也能用空间透视页
看构成、做大文件回收站与迁移。只有以下系统级项目需要管理员：

| 需要管理员 | 原因 |
|---|---|
| Windows 系统临时文件（`C:\Windows\Temp`）、Prefetch | 系统目录，普通用户无写权限 |
| Windows 更新下载缓存、传递优化缓存 | 系统服务目录 |
| CBS / 系统日志（`C:\Windows\Logs`）、系统错误报告（WER 全机） | 系统目录与 ProgramData |
| 清空回收站（含其他用户的项） | `C:\$Recycle.Bin` 下其他 SID 目录 |
| WinSxS（DISM）、休眠文件（powercfg）、还原点（vssadmin） | 系统维护命令，**工具只给命令不代执行** |

进入管理员模式的两种方式：

1. 界面右上角点「以管理员身份重启」——会以管理员身份重启同一个程序，并保留当前页面；
2. 右键 `QingFengCleaner-onedir\QingFengCleaner.exe` 或 `启动清风清理.bat` →「以管理员身份运行」。

不提权时，需要管理员的规则会显示「需要管理员权限」并跳过（不是报错），用户级清理照常可用。

## 3. 命令行参数

```
python main.py [选项]
```

| 参数 | 说明 |
|---|---|
| *(无参数)* | 启动图形界面，含系统托盘，默认显示「清理」页 |
| `--page clean\|space` | 启动时显示页面：`clean`=清理页（默认），`space`=空间透视页（v2） |
| `--scan-only` | **只扫描并打印报告**，不启动界面、不删除任何文件，退出码 0 |
| `--no-tray` | 不启用系统托盘（关闭窗口即退出，便于调试） |
| `--hidden` | 启动时直接隐藏到托盘，不弹出主窗口 |
| `--rules-dir <路径>` | 使用自定义规则目录，替代内置 `qingfeng/data/rules/` |
| `--version` | 打印版本号（如 `清风清理 0.1.0`）并退出 |
| `-h`, `--help` | 打印帮助 |

### 示例

```bat
:: 只扫描，看看 C 盘能清出多少（最常用、最安全）
python main.py --scan-only

:: 直接打开「空间透视」页（v2）
python main.py --page space

:: 不启用托盘（窗口关掉就退出，方便调试）
python main.py --no-tray

:: 后台静默启动到托盘，适合开机自启
python main.py --hidden

:: 用自己写的规则集扫描
python main.py --scan-only --rules-dir D:\my-rules

:: 查看版本
python main.py --version
```

## 4. 自定义规则目录

`--rules-dir` 指定的目录下放一个或多个 JSON 文件，格式与内置规则一致（见
[`docs/ARCHITECTURE.md`](ARCHITECTURE.md) §4）：

```json
{
  "version": 1,
  "category": "应用",
  "rules": [
    {
      "id": "my-app-cache",
      "name": "某应用缓存",
      "category": "应用",
      "description": "某应用下载缓存目录",
      "action": "delete",
      "paths": ["%LOCALAPPDATA%\\MyApp\\cache"],
      "globs": ["*"],
      "exclude_globs": [],
      "risk": "caution",
      "requires_admin": false,
      "default_enabled": true,
      "min_age_days": 0,
      "follow_dirs": true,
      "source": "self"
    }
  ]
}
```

- `paths` 支持 `%TEMP%`、`%LOCALAPPDATA%`、`%APPDATA%`、`%WINDIR%`、`%USERPROFILE%` 等环境变量。
- `action` 取值：`delete`（可清理）、`empty_recycle_bin`（清空回收站）、`report`（只报告建议命令）。
- 自定义规则**同样受 `safety.py` 保护路径限制**，写规则也删不到系统目录。
- 加载阶段会校验规则，非法字段直接报错退出，不会半加载。

## 5. 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 正常结束（扫描完成 / 界面正常退出） |
| `1` | 运行期错误（规则加载失败、引擎异常等），详见 stderr |
| `2` | 参数错误（argparse 用法错误） |

## 6. 卸载

- 打包版：删除整个解压目录（`启动清风清理.bat` + `QingFengCleaner-onedir\` 一起删）即可；
  不写注册表、不留服务、不留开机项。
- 源码版：删除整个项目目录，并删掉 `.venv/`（如创建过）。
- 想清掉本地缓存：删 `%LOCALAPPDATA%\QingFengCleaner\`（里面有空间索引缓存 `space_index.json` 和设置）。
- 清理出来的文件在**回收站**里，确认无误后自行清空即可；迁移出去的文件在目标盘的 `C_mirror\` 目录里。
