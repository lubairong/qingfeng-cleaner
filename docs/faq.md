# 常见问题 · FAQ

## 1. 这东西安全吗？会不会误删我的文件？

**默认只扫描，不删除。** 必须由你手动勾选规则、再点「清理选中」、再在二次确认框里确认，才会真正删除。
启动后的第一屏永远是扫描结果，不会自动清任何东西。

即使误点了，还有四道保险：

1. **删除走回收站**（`SHFileOperationW` + `FOF_ALLOWUNDO`），删错可以去回收站还原；
   「永久删除」是单独的开关，默认关闭。
2. **保护路径白名单**在 `qingfeng/core/safety.py` 里硬编码，规则和界面都改不了：
   `C:\Windows`、`C:\Program Files`、`C:\Users\<你>`、`C:\System Volume Information` 等等，
   对这些路径的删除请求会直接抛 `UnsafePathError` 拒绝。
3. **规则本身受限**：每条规则只能删自己声明的目录（`within_root` 防路径穿越），
   且必须过 `min_age_days` / `exclude_globs` 过滤。
4. **高级规则默认关闭**：隐私痕迹、系统维护类规则默认不勾选，需要你主动打开。

代码全部开源，你可以逐行审计；也可以先只用 `python main.py --scan-only` 看看它能扫出什么。

## 2. 清理完 C 盘会变快吗？

**不会明显变快，但会多出空间。**

- 清理的是临时文件、缓存、日志——它们本来就不拖慢系统性能。
- 真正影响开机/运行速度的是启动项过多、机械硬盘碎片、内存不足、杀软冲突等，不是垃圾文件。
- 唯一的例外：**C 盘剩余空间低于 10%~15%** 时，系统会因为空间不足而卡顿、更新失败、
  虚拟内存吃紧。把空间清出来，这种「空间不足导致的卡顿」会消失。

所以合理预期是：**腾出几个 GB 到几十 GB 空间，顺便减少一点磁盘占用**，而不是「一键提速 300%」。
市面上「一键提速」类宣传基本是营销话术。

## 3. 为什么有些功能需要管理员权限？

Windows 的权限模型决定：普通用户进程只能改自己 `%USERPROFILE%` 下的东西。

需要管理员的操作包括：

| 操作 | 为什么 |
|---|---|
| 清理 `C:\Windows\Temp`、`C:\Windows\Logs` | 系统目录，普通用户无写权限 |
| 清理 Windows 更新缓存（`C:\Windows\SoftwareDistribution\Download`） | 属系统服务目录 |
| 清空回收站（其他用户的部分） | `C:\$Recycle.Bin` 下有其他 SID 的目录 |
| 删除休眠文件 `hiberfil.sys` | 系统文件，需 `powercfg /h off` |
| 关闭系统还原 / 删除还原点 | 需 `vssadmin` 权限 |

清风清理的做法是：

- **非管理员下不静默失败**：相关规则会显示「跳过：需要管理员权限」，并能一键「以管理员身份重启」。
- 危险操作不硬删，而是给出**建议命令**（`action: "report"`），由你自己决定要不要执行。
- 普通用户权限下仍然可以清理**用户级**的大头：`%TEMP%`、浏览器缓存、应用缓存、缩略图缓存。

## 4. 回收站删掉的东西去哪了？怎么彻底删除 / 怎么还原？

- **去哪了**：文件被移动到当前盘的回收站目录，例如 `C:\$Recycle.Bin\<用户SID>\`。
  它仍然占着磁盘空间，只是「逻辑上」不在原位置了。所以清理完 C 盘可用空间会立刻变多，
  但**回收站还占着配额**——确认没问题后清空回收站，空间才真正释放。
- **怎么还原**：打开回收站 → 找到文件 → 右键「还原」，会回到原路径（原目录不存在时会提示）。
- **怎么彻底删除**：右键回收站「清空回收站」，或用界面里的「清空回收站」动作（需二次确认）。
- **想直接永久删除**：在设置里打开「永久删除（不经过回收站）」开关。**不建议**，
  除非你已确认规则绝对安全——永久删除的文件无法用常规手段恢复。

> 提示：回收站对每个盘有容量上限（默认约 5%~10%）。文件太大超过上限时，Windows 可能直接永久删除而不入回收站。
> 本项目在清理前会提示预估体积。**空间透视页不提供「永久删除」** —— 那一页只有「移入回收站」，永久删除开关只在清理页。

## 5. 会不会删掉我正在用的文件 / 导致软件异常？

规则层面的防护：

- 大部分规则设置了 `min_age_days`，只处理「N 天前的旧文件」，正在被写入的文件不会被选中。
- 正在使用的文件（被进程锁定）删除会失败，程序会把这些失败项收集到报告里，不影响其他文件。
- 浏览器规则**只清缓存**，绝不包含密码、书签、Cookie、历史记录数据库（除非显式的 advanced 隐私规则）。
- 清理前可先看「大小 / 文件数 / 风险」三列，不确定的规则取消勾选即可。

建议：第一次使用时先只勾「安全」级规则，观察几天没问题后再考虑其他。

## 6. 支持清理 D 盘、E 盘吗？

清理规则仍聚焦 **C 盘**（系统盘）——这是绝大多数人空间告急的地方；临时文件规则用环境变量（如 `%TEMP%`），不写死盘符。

**v2 起支持把 C 盘大文件「迁移」到 D/E 等固定磁盘**：空间透视页勾选大文件 →「迁移到目标」→ 选目标盘目录。
迁移会保留 `<目标盘>\C_mirror\<原相对路径>` 结构、**复制成功后才删除源文件**，失败或取消时源文件不动。
迁移目标必须是可写的固定磁盘（移动硬盘/U 盘等可移动磁盘不作为目标）。

## 6.1 为什么建议迁移，而不是直接删除？

因为**迁移不丢数据**：文件还在，只是从 C 盘换到了 D/E 盘，C 盘立刻腾出空间，后悔了还能搬回来（目标盘
`C_mirror\` 里能找到原位）。删除（哪怕进回收站）最终仍要清空回收站才真正释放空间，一旦清空就找不回了。

所以对「视频 / 镜像 / 备份包 / 虚拟机磁盘」这类**你还需要用**的大文件，界面默认给的建议是「建议迁移」；
只有「安装包 / 升级残留 / 旧版本副本」这类**大概率不再需要**的才会建议清理。

## 6.2 为什么有些大文件显示「受保护·不可操作」？

因为这些文件在**不该动的地方**：`C:\Windows`、`C:\Program Files`、`C:\Program Files (x86)`、
`C:\ProgramData`（除个别软件自己的安装包下载目录）、`System Volume Information`、回收站等。
删它们轻则程序损坏，重则系统起不来，所以工具只展示、不允许删除或迁移，并在按钮上写明原因。

其它情况：

- **「建议保留」组**（模型/数据库/微信聊天数据等）默认不勾选，提醒你别误删；
- 非管理员运行时，需要提权的操作会提示「需要管理员」，可点右上角「以管理员身份重启」；
- 若一项同时是文件夹的子项，会被父目录吸收（避免重复计数/重复删除）。

## 6.3 空间索引为什么要几十秒？会不会上传？

- **为什么要几十秒**：空间透视要把 C 盘每个目录的大小都算出来（本机约 40 万文件 / 122 GB），
  并做硬链接去重（同一 inode 只计一次），否则 Windows 目录会被重复计算得虚高。这是纯本地遍历，一次性成本。
- **会不会一直这么慢**：不会。索引结果缓存 24 小时，再次打开秒开；「重新扫描」才会重建。
- **会不会上传**：**不会**。零网络代码、无遥测；缓存只写 `%LOCALAPPDATA%\QingFengCleaner\space_index.json`，
  不写注册表。扫描是只读的，不会修改被扫目录的修改时间。
- 扫描过程可随时「取消」，已统计部分不会白费；索引失败也不影响「清理」页继续用。

## 7. 杀毒软件报毒 / SmartScreen 拦截怎么办？

常见原因：exe 由 PyInstaller 打包、**没有代码签名**，会被启发式引擎或 SmartScreen 拦。

- SmartScreen：「更多信息 → 仍要运行」。
- 杀软误报：把 exe 加入信任，或直接**用源码运行**（`packaging\run_dev.bat`），源码运行不会被拦。
- 想完全避免：自己打包（`packaging\build.ps1`），或用你自己审计过的源码。

## 8. 会联网 / 上传我的文件列表吗？

**不会。** 本项目零第三方依赖、无网络代码、无遥测、无统计上报，所有扫描、索引、清理与迁移都在本地完成。
你可以断网运行验证，或直接审计源码（`qingfeng/` 目录，纯标准库 + ctypes）。

## 9. 为什么不用 CCleaner / 某某管家？

- 想用就用，本项目不评价友商。
- 清风清理的定位：**开源、可审计、零依赖、默认最保守**。适合「只想要一个干净的清 C 盘工具」的人。
- 没有广告、没有捆绑、没有后台常驻服务、没有会员。

## 10. 扫描很慢 / 卡在某个规则上怎么办？

- 全盘规则首次扫描会遍历大量小文件，10~60 秒属正常。
- 扫描在后台线程进行，界面不会假死；可随时点「取消」。
- 如果某条规则特别慢（例如大目录），可在设置里单独禁用它，或在 Issue 里反馈规则 id。

## 11. 双击 exe 没反应 / 报错怎么办？

v2.1 起**只交付目录版**，正确用法是：解压后双击 `启动清风清理.bat`（或
`QingFengCleaner-onedir\QingFengCleaner.exe`）。注意：目录版必须连同 `QingFengCleaner-onedir\_internal\`
一起使用，只拷走 exe 会启动失败。

其他常见原因与处理：

- **SmartScreen / 杀软拦截**：见上一问（未知发布者 →「更多信息 → 仍要运行」）。
- **没有管理员权限**：普通权限下程序能启动、能扫描，只是部分「需要管理员」的规则会被跳过；
  需要清理系统目录时点界面右上角「以管理员身份重启」，或右键 exe「以管理员身份运行」。
- **想看到具体报错**：用命令行启动而不是双击：

  ```bat
  :: 目录版（在解压出来的目录里）
  QingFengCleaner-onedir\QingFengCleaner.exe --scan-only
  :: 或
  启动清风清理.bat --scan-only

  :: 源码版
  python main.py --scan-only
  ```

  如果报错信息与 exe 启动有关（而不是扫描规则），把完整输出贴到 Issue 里，并注明是源码版还是打包版。

## 12. 为什么没有单文件版？双击提示 Could not create temporary directory 怎么办？

**因为没有单文件版了。** PyInstaller 的 onefile exe 每次启动都要先把自身解压到系统临时目录；
实测在**中文路径**（以及临时目录受限）环境下会弹出
`Could not create temporary directory!`，进程挂起或直接失败；同一个 exe 复制到纯 ASCII 路径才正常——
对用户来说太不可靠，因此 v2.1 起**从交付物里移除了单文件版**。

遇到这个提示时的处理：

1. 改用**目录版**：`QingFengCleaner-onedir\QingFengCleaner.exe` 或 `启动清风清理.bat`；
2. 如果你是在做开发实验：单文件版只作为实验产物存在（`packaging\build.ps1 -OneFile`，
   输出 `dist\_experimental\`），不属于正式发布；
3. 也可以直接源码运行（`packaging\run_dev.bat`），功能完全一致。

## 13. 哪些功能需要管理员？怎么提权？

**不提权也能用**：`%TEMP%`、浏览器/应用缓存、回收站等用户级缓存都能清理，空间透视和迁移也能用。
只有系统级项目需要管理员：`C:\Windows\Temp` / Prefetch、Windows 更新缓存、CBS 与系统日志、
系统错误报告（全机）、清空回收站（含其他用户）、WinSxS（DISM）/休眠文件（powercfg）/还原点（vssadmin）。

提权方式：

1. 界面右上角「以管理员身份重启」——以管理员身份重启同一个程序并保留当前页面；
2. 右键 `QingFengCleaner-onedir\QingFengCleaner.exe` 或 `启动清风清理.bat` →「以管理员身份运行」。

不提权时，需要管理员的规则会显示「需要管理员权限」并跳过（不算报错），不影响用户级清理。

## 14. 支持 Windows 10 / 7 吗？

主要面向 **Windows 11**；Windows 10 21H2+ 一般可用。Windows 7 未测试（部分 API 行为不同），不承诺支持。
